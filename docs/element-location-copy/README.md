# ページ内のアドレスとコピー操作

画面を見ながら変更や質問をしたい場所をチャットで伝えられるよう、ページ名とその場所の表示名を1行でコピーできるようにする。

## 適用範囲

- 新しいページの提案・設計時には、チャットで「この場所について」と個別に指したいまとまりを決める。「絞り込み」「共通条件」など独立した設定セクションも、表・グラフなどの結果も対象とする。案には各対象のコピー位置と文字列を示し、実装にはそれぞれ1つのコピー操作を用意する。
- 既存ページでは、新しく追加する設定セクション・出力・表示形式と、標準構造に移す範囲にこの基準を適用する。既存部品を再利用する場合も同様とする。親にコピー操作がなくても、その表示名は子の場所を特定するのに必要ならアドレスに含める。
- 既存要素への遡及は依頼された範囲で行う。既存の表の列幅を直すときなど、通常の修正で周辺まで一括移行する必要はない。
- 個々のボタン・入力欄・セル・データ点は、所属するセクションや結果のアドレスで指す。たとえば「敵の防御力」欄について話すときは、「共通条件」のアドレスに画面の項目名を添える。

## 書式と部品

アドレスはページ名から始め、セクション・タブ・パネル・表示形式のうち、その場所を特定する表示名を順につなぐ。画面のラベル定義と選択中のタブ・表示形式を使う。検索語や設定値を変更しても、同じ場所は同じアドレスで指せるようにする。URLや内部IDは含めない。

```text
〈防御力と術耐性の対応 / 順位帯の統計 / グラフ〉
```

[PageLayout](../../src/components/PageLayout.tsx) の `page` に登録済みのページIDを渡す。配下の `PageOutputTabs` と `PageOutputHeader` は、この登録名をアドレスの先頭に使う。右端の [ElementLocationCopyButton](../../src/components/ElementLocationCopyButton.tsx) が各要素を ` / ` でつなぎ、全体を `〈〉` で囲んで [writeClipboardText](../../src/lib/clipboard.ts) でコピーする。

| 対象 | コピー操作の配置と内容 |
| --- | --- |
| 独立した設定セクション | 見出し行の右端にコピーを置く。`PageOutputHeader` の `segments` に見出し名を渡す。リセットなど同じ行の操作はコピーの左に置く。 |
| 複数のタブ | `PageOutputTabs` がタブ列の右端に1つ置く。選択中のタブ名は自動で入り、`format` に現在の表示形式のラベルを渡せば末尾に加わる。 |
| 単一の出力 | `PageOutputHeader` が操作列や表示切替の右端に置く。`segments` にはページ内の階層だけを渡し、ページ名で特定できる場合は省略する。単一の出力用にタブや本文のページ見出しを作る必要はない。 |
| 個別のパネル | パネル見出し帯の右端に置き、見出し名をアドレスに含める。既存のパネルで `ElementLocationCopyButton` を直接使う場合は、ページ名を含む全階層を `segments` に渡す。 |

「防御力と術耐性の対応」のタブ列では、次のように表示中の形式を渡す。`tabProps` はタブ列とパネルで共有する `idPrefix` と `activeTab`。`formats[tab]` は切替ボタンと同じラベルで、「順位表」では `null` になるためタブ名までをコピーする。

```tsx
<PageLayout page="enemy-defense-resistance">
  <PageOutputTabs {...tabProps} tabs={TABS} onChange={setTab} label="分析項目" format={formats[tab]} />
</PageLayout>
```

単一の出力で表・グラフを切り替える場合は、`<PageOutputHeader segments={[viewLabel]}>{viewSwitch}</PageOutputHeader>` のように、そのページの表示形式名と表示切替を渡す。コピー内容を常時表示する欄やツールチップは設けない。

## 表示と検証

- 設計で決めた各セクション・結果を実際にコピーし、貼り付けた文字列で場所を区別できることを確かめる。設定セクションは入力値の変更前後で同じ文字列になることも確認する。
- [ボタンの共通スタイル](../../src/components/ElementLocationCopyButton.css)がアイコンと押下領域を定める。狭い画面やタッチ操作でも押しやすく、コピーの成否を示すアイコンで列幅が変わらないことを確認する。
- キーボードでコピーし、成功・失敗の読み上げ、失敗後の再試行、処理中にタブや表示形式を切り替えたときの通知を確認する。
- ボタンは画面の操作列に置く。表やグラフを画像・動画として保存するときは、出力範囲からボタンとアドレスを除く。

## 適用例

[防御力と術耐性の対応](../../src/components/EnemyDefenseResistancePage.tsx)では、タブ列の1つのボタンで4タブ・8通りの表示に対応する。[コピー内容の見本](examples/paths.txt)に各表示のアドレスを1行ずつ示す。表示名や構成を変えたときは、各タブで実際にコピーした文字列と見本を照合して更新する。

[DC3 スキル比較](../../src/components/DamageCalculatorThreeComparisonPage.tsx)では、設定と結果をそれぞれの見出しからコピーできる。

```text
〈DC3 スキル比較 / 絞り込み〉
〈DC3 スキル比較 / 共通条件〉
〈DC3 スキル比較 / 計算結果〉
```
