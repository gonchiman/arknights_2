# ステータス指標の共通配色

## 用途と適用範囲

単体の分布から複数指標の比較へ移っても、同じステータスを同じ色で識別できるようにする。共通の棒グラフ作成ページの単体分布・評価別比較・順位帯統計と、既存の敵統計のヒストグラム・防御力と術耐性の評価別比較に適用する。画面、保存プレビュー、実際のPNG、これらの描画から作る既存の動画で同じ対応を使う。

対象はHP、攻撃力、防御力、術耐性、移動速度、攻撃間隔、重量の7指標。PCA、DC3、散布図、箱ひげ図、単独の累積分布などへの一括適用は行わない。MOD・敵の等級・平均や中央値など、別の意味を表す配色も変更しない。

## 固定仕様と可変部分

### 指標の識別

色は指標IDで決める。単体グラフでは `document.semantics.metricKey`、左右比較では各 `series.metricKey` を保持する。既存の敵統計では同じ指標定義の `metric.key` を使う。表示名、系列の追加順、左右の位置、階級方式から色を推測しない。

| 指標ID | 表示名 | 配色の識別 |
| --- | --- | --- |
| `maxHp` | HP | 緑 |
| `attack` | 攻撃力 | 紫 |
| `defense` | 防御力 | 青 |
| `magicResistance` | 術耐性 | オレンジ |
| `moveSpeed` | 移動速度 | 青緑 |
| `baseAttackTime` | 攻撃間隔 | 赤紫 |
| `massLevel` | 重量 | 黄土色 |

正確な色値は `STAT_METRIC_COLORS` を正とし、この表に別の色値を持たせない。攻撃間隔の単位は秒であり、攻撃速度とは区別する。未定義のキー、キーの省略、登場ステージ数などの派生指標は `getStatMetricColor` が返す共通の中性色を使う。

7色は白を20%混ぜた明るいトーンとし、通常の棒の不透明度は1を維持する。

左右を入れ替えても指標の色を維持する。同じ指標を左右に置いた場合も同じ色とし、左右の位置と直接ラベルで識別する。単体の棒と比較の棒で独自の薄色・濃色を作らず、通常の棒の不透明度は `STAT_METRIC_BAR_OPACITY` を使う。

共通の棒グラフに追加する順位帯統計も、標準化した値の大きさ・符号や統計量名ではなく、元の `series.metricKey` の指標色を使う。最小・最大・幅・平均・標準偏差・分散を切り替えても、防御力は防御力の色、術耐性は術耐性の色を維持する。統計量から割合や累積線は作らない。

### 累積割合と他の意味色

ヒストグラムに重ねる累積割合線は `STAT_CUMULATIVE_COLOR` の濃灰、`STAT_CUMULATIVE_DASH_ARRAY` の破線とする。線上の点と累積割合の右軸名も同じ濃灰を使い、棒の指標色から補助的な累積割合の線を区別する。

既存の評価別比較の「累積折れ線」（`CUMULATIVE`）は、防御力と術耐性それぞれの累積分布を比較する2系列なので、各指標の色と既存の線種・点の形を維持する。ヒストグラムに重ねる単一の補助線と区別し、両系列を濃灰の同じ線へ置き換えない。

既存の敵統計の上限超過階級は、従来の赤い表示を維持する。指標色の適用を理由に上限超過の区別を消さない。平均・中央値の基準線、等級、エラー、選択範囲の強調、情報帯の背景、MODなども、それぞれの既存の意味を保つ。全体の `--danger` や `--link` などを指標色へ置き換えない。

指標・集計版・範囲・階級・表示する系列は利用ごとに変えられる。色と通常の棒の不透明度、累積線の書式は共通定義に固定し、ページごとの色入力や別パレットを追加しない。色だけに識別を任せず、指標名・軸名・直接ラベルを維持する。

## 使い方

対象の指標定義や固定スナップショットにあるキーを渡す。下記の `metric` は利用側の選択指標を表す。

```ts
import { getStatMetricColor, STAT_METRIC_BAR_OPACITY,
  STAT_CUMULATIVE_COLOR, STAT_CUMULATIVE_DASH_ARRAY } from './statMetricColors'

const barColor = getStatMetricColor(metric.key)
const barOpacity = STAT_METRIC_BAR_OPACITY
const cumulativeColor = STAT_CUMULATIVE_COLOR
const cumulativeDashArray = STAT_CUMULATIVE_DASH_ARRAY
```

描画の色、対応する系列名、凡例がある場合の色見本へ同じ値を渡す。保存時もスナップショットの指標IDから同じ共通色を使い、保存プレビューのための別の配色を定義しない。

PNG生成は既存の `ChartImageFrame` と `saveComparisonChartImage` を使う。描画済みSVGの塗り・線色・破線を保存する既存経路を維持し、保存処理に指標名の判定やパレットを持ち込まない。既存のヒストグラム・評価別比較の動画も同じ描画の色を利用し、新しい動画保存機能は追加しない。

## 見本と更新方法

確認用PNGはアプリの実際の画像保存から生成する。手描きの色見本や画面のスクリーンショットで出力確認を代用しない。確認用データの版・件数・階級の数値は、今後の出力に固定しない。

以下は集計版v12・メインストーリー・出現回数、幅1,920px・比率16:9で生成した確認用PNG。v12の実データから作った固定スナップショットを `getBarChartImageFrame`・`ChartImageFrame` へ渡し、実際の `saveComparisonChartImage` の `writeBlob` で保存先を受け取って生成したもの。画像の合成や描き直しではなく、アプリと同じ描画・PNG生成処理の結果を保持する。

| 確認する出力 | 表示設定 |
| --- | --- |
| [防御力の単体分布](examples/defense-rating.png) | ゲーム内評価で区分し、累積割合線・帯と割合帯を表示 |
| [術耐性の単体分布](examples/resistance-rating.png) | 防御力と同じ表示設定 |
| [防御力・術耐性の比較](examples/defense-resistance-rating.png) | 左右比較、外側は累積割合、強調なし |

更新するときは共通の棒グラフ作成ページで同じ集計・表示条件を指定し、「画像を保存」から上記のファイル名で出力する。保存先だけを受け取る確認用の呼び出しでも、同じ固定スナップショット・共通フレーム・PNG生成処理を使う。

単体の防御力から術耐性、両者の比較へ順に並べ、防御力の青・術耐性のオレンジが同じ色・不透明度を保つこと、累積線だけが濃灰の破線として識別できることを確認する。既存の敵統計も同じ指標・集計条件で保存し、共通の棒グラフと色・線種を照合する。

残る5指標も単体で確認する。数値階級、ゲーム内評価、左右の入替、同じ指標の比較、画面のテーマ、保存プレビュー、実PNGで識別が変わらないことを確認する。既存の動画出力では棒・点・累積線・軸名に同じ色と破線が反映されることも確認する。

## 適用状況

| 対象 | 適用範囲 |
| --- | --- |
| 共通の棒グラフ作成ページ | 7指標の単体分布、4指標の評価別比較、防御力・術耐性の順位帯統計と、それらの保存プレビュー・PNG |
| 既存の敵統計 | ヒストグラムの通常の棒と重ねる累積割合線、防御力・術耐性の評価別比較、その既存の画像・動画出力 |
| PCA・DC3・散布図・箱ひげ図・単独の累積分布など | 今回は移行しない |

他のグラフへ適用するときは、その図で色が表す意味と既存の適用範囲を確認する。この仕様への登録を既存グラフの一括変更の指示として扱わない。

## 変更時の確認

- 7指標が共通定義を使い、単体・比較・左右の入替で同じ指標の色が変わらない。同じ指標の2系列も同じ色を保つ。
- キーなし・未知のキー・派生指標は中性色とし、表示名の文字列を見て既知の色へ変換しない。
- 単体と比較の通常の棒で、不透明度が一致する。上限超過の赤は保持する。
- 累積割合の線・点・右軸名が同じ濃灰で、線が共通の破線を使う。値や軸・階級・度数・割合の計算は変わらない。
- 2指標を比較する「累積折れ線」は各指標の色と既存の線種・点の形を保持し、ヒストグラムの補助線用の濃灰破線と混同しない。
- 画面・保存プレビュー・実PNGが同じ色と線種を示す。PNGで黒い棒や実線へ変わらない。
- 既存の動画にも色と破線が反映され、PCA・DC3・散布図・箱ひげ図・単独の累積分布やMODの色は変わらない。
- 共通定義と関連テスト、アプリのビルド、`npm run rules:check`、生成したPNGを確認する。配色を変更した場合は確認用出力も再生成する。
