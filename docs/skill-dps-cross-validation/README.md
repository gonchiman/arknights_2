# スキルDPSの交差検証の版管理

## v1 組み合わせ評価の交差検証

オペレーター単位の交差検証を追加し、3方式の予測誤差を比較できるようにした。

- 計算規則 `skill-dps-cross-validation/v1`。組み合わせ評価と同じ適用済みの絞り込み・DPS指標・候補変数を使い、DPSと候補変数がすべて揃うスキルを選ぶ。オペレーターを1人ずつ取り分け、残りのオペレーターのデータで回帰式を作る。[計算コード](../../src/lib/skillDpsCrossValidation.ts)
- 組み合わせの選び方は、調整済みR²最大、調整済みR²が首位の0.5ポイント以内で最大VIF最小、攻撃力・攻撃間隔の固定の3方式。変数を選択する2方式は各回の訓練データ内で2変数以上の組み合わせを評価し直す。固定方式には攻撃力・攻撃間隔の両方が必要。
- 選択時は2指標のうち各方式が優先する指標、もう一方の指標、変数数の少なさ、変数IDの順で比較する。
- 誤差は全回の予測をスキル単位で合わせて集計する。MAEは絶対誤差の平均、RMSEは二乗誤差の平均の平方根。全対象の予測を揃えられない方式は集計できない。

### 初版の照合条件と結果

日本版ゲームデータ `270115d3ef5dc0e97530bedc168eb3ddb3d14bc6`。対象は全職業・全レアリティ・全ダメージ属性の自然回復スキル。最高スキルレベル、信頼度100、潜在1、モジュールなし、敵1体、防御力0・術耐性0の直接DPSを使う。理論稼働率を外し、持続時間・必要SP・必要SP−初期SP・配置コスト・初期SP率・攻撃力・攻撃間隔を候補とした。この条件の対象は258スキル、183オペレーター。

| 組み合わせの選び方 | MAE（DPS） | RMSE（DPS） |
| --- | ---: | ---: |
| 調整済みR²が最高 | 346.34 | 562.33 |
| 首位から0.5ポイント以内で最大VIFが最小 | 344.89 | 557.41 |
| 攻撃力・攻撃間隔に固定 | 343.62 | 563.55 |

元データや対象、計算規則の変更で結果が変わる場合は、新版に使用したデータ、変更内容、照合条件と結果を記録する。
