# 防御力と術耐性の組み合わせ

## 集計規則 v1

初版では、同じ敵IDの基礎防御力・術耐性の組を、ゲーム内評価の10段階または「A以下・A+以上」の4通りで集計する。

- 敵と重みは選択中の[敵集計版](../../public/data/enemy-aggregation/index.json)と集計範囲に従う。絞り込み後の敵IDを1回ずつ扱う。
- 種類数は敵IDにつき1、登場マップ数（延べ）は敵IDごとの登場マップ数、出現回数は敵IDごとの出現回数を加算する。出現回数に下限や期待値を含む版ではその重みを引き継ぐ。
- 両方の基礎値が有限のとき、[ゲーム内評価の境界](../../src/lib/enemyStatRatings.ts)で分類する。0も有効。どちらかが欠測の敵は、その集計方法の重みを除外数に加える。
- 横軸は防御力、縦軸は術耐性。4マス表示ではA+以上（防御力1,200以上、術耐性60以上）をそれぞれ1区分にまとめる。高防御の敵に占める高術耐性の割合は、両方がA+以上の重みを防御力A+以上の重みで割る。

### 初版の検証値

敵集計v12・メインストーリー・全敵・出現回数で、有効11,409回、除外201回。防御力・術耐性が両方ともA+ちょうどのセルは184回。

| 術耐性 ＼ 防御力 | A以下 | A+以上 |
| --- | ---: | ---: |
| A以下 | 10,859 | 129 |
| A+以上 | 123 | 298 |

防御力A+以上の427回のうち術耐性もA+以上は298回（69.8%）。[回帰テスト](../../tests/enemyRatingPairs.test.ts)は保存済みのv12を読み、10段階をまとめ直した値と4マスの値を照合する。
