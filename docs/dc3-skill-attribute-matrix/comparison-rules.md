# スキル別の物理・術ダメージの比較規則

「主攻撃の属性変更」「術耐性別の統計」「出現敵での比較」は、同じ主攻撃を物理・術にしたときのダメージを比較し、属性限定効果の設定を共有する。「実際のダメージ内訳」は元の攻撃属性を使い、防御力・術耐性無視のチェックを独立して持つ。

## v10

「出現敵での比較 / 属性別の優勢率」に、防御力と術耐性の上側外れ値を組み合わせた4区分を追加した。

敵集計版と集計範囲を選び、防御力と術耐性が両方分かる敵の出現回数で第1・第3四分位数を求める。各ステータスで「第3四分位数 ＋ 1.5 ×（第3四分位数 − 第1四分位数）」を超える値を上側外れ値とする。境界と同じ値は範囲内に含む。「エリート＋ボス」に切り替えたときも、選択中の集計版・集計範囲の全敵から求めた境界を使う。

出現割合の分母は、選んだ対象敵（全敵、またはエリート＋ボス）の両ステータスが有効な出現回数。優勢率の分母は、その区分で比較できた物理・同値・術の重み付き得票の合計で、得票はv5の規則に従う。スキルの絞り込みと集計単位は優勢率に反映する。対象敵がいても有効票がない区分では出現回数・出現割合を表示し、優勢率は「—」とする。

v9と同じ日本版データ・敵集計v12・メインストーリーの標準条件では、防御力の境界は422.5、術耐性の境界は75。スキル単位（752スキル）の結果を示す。

## v9

「出現敵での比較 / 属性別の優勢率」に職業別・レアリティ別の内訳を追加した。

絞り込み後のスキルをオペレーターの職業またはレアリティでまとめる。各カテゴリでは、v5の規則で得た物理・同値・術の票を丸めずに合算し、それぞれをカテゴリの総得票で割る。「全体」行には、絞り込み後の全スキルの票を用いる。

有効スキル数・有効段階数は、少なくとも1組の出現敵で比較できたスキル・段階の数。0件のカテゴリは、表では割合を「—」、グラフでは「対象なし」と表示する。標準条件の事前集計には両方の集計単位での内訳を保存する。

## v8

「出現敵での優勢率」に、主攻撃1回の物理・術の平均ダメージとその差を、全体と防御力帯別に追加した。

1. v5と同じ敵の防御力・術耐性の組に対し、主攻撃を物理と術で計算する。両方の値が有効な段階を使う。0ダメージも有効とする。
2. 敵の組ごとに、各スキルの有効段階を属性別に等しく平均し、その組で比較できた各スキルの平均を等しい重みで平均する。段階数の異なるスキルも1スキル分の重みを持つ。
3. その値に各組の出現回数を掛け、合計を比較可能な組の出現回数で割る。防御力帯別の平均はその帯の出現回数を分母とする。差は丸める前の物理平均から術平均を引いた値。対象の出現回数が0の帯では平均と差を「—」とする。

### 標準条件の事前集計

メインストーリー・スキル単位・属性限定効果を除外・全出力型・絞り込みなしの結果は、公開前に通常のDC3で計算して同梱する。「出現敵での優勢率」の表・グラフ、スキルごとの物理優勢率のヒストグラム、「主攻撃1回の平均ダメージ」は、全体・防御力帯別ともこの集計を参照できる。条件を変えたときや、オペレーターを選んで票の内訳を見るときは、表示対象について通常の計算を行う。

敵の集計版・日本版のゲームデータ・DC3の計算を更新したら、開発サーバーで日本版のローカルデータを取得した作業フォルダで `npm run generate:dc3-enemy-default` を実行する。生成された [標準条件の集計結果](../../src/data/damageThreeEnemySpawnDefault.json) を確認し、更新に含める。ファイルには敵の集計版、日本版データのリビジョン、照合用のハッシュ、丸める前の結果を保存する。

ページは読み込んだ敵・スキルのデータが保存時と一致する場合に事前集計を使う。DC3の計算コードと保存時のハッシュが異なる場合は、開発用ページでは通常の計算に切り替え、公開用ビルドでは再生成を求める。

## v7

「出現敵での優勢率」に、各オペレーターの対応スキルが物理・同じ・術に何票ずつ加えたかと、敵の組ごとの判定内訳を追加した。

v5のスキル単位の得票を使う。ある敵の組でスキルの比較可能な段階が2つなら、各段階は1回の出現につき0.5票を持つ。各段階でダメージを比較し、その判定に「出現回数 ÷ 比較可能な段階数」を加える。比較可能な段階がない組は、そのスキルに0票を加える。オペレーターの合計は、選択中の条件を満たす各スキルの得票を足した値である。

v6と同じ検証条件では、属性変更に対応する段階を持つ351人が選択候補になる。選んだオペレーターの全段階で比較できるダメージが得られない場合は、その旨を表示する。得票があるのは345人・752スキルで、対象の出現回数は11,409回。スルトS3の票は物理7,558・同じ901・術2,950。ヴィジェルS3では、防御力100・術耐性20の647回の出現について、本人の攻撃が物理、狼の群れの攻撃が術に各323.5票を加える。

## v6

「出現敵での優勢率」に、スキルごとの物理優勢率を10ポイント刻みで数えた分布を追加した。

1. v5と同じ敵・出現回数・ダメージ判定を使う。各スキルについて、敵の防御力・術耐性の組ごとに、物理が高い段階数を比較可能な段階数で割る。同値の段階も分母に含める。
2. その割合を、比較可能な組の出現回数で加重平均する。比較可能な組がないスキルは対象外とする。すべて同値のスキルの物理優勢率は0%になる。
3. 丸める前の物理優勢率で1スキルを1回だけ数える。階級は下端を含み上端を含まない10ポイント幅とし、最後の階級に100%を含める。

v5と同じ検証条件（敵集計v12、メインストーリー、全出力型、絞り込みなし、属性限定効果を除外）では11,409回の出現に対して752スキルが対象となる。

## v3

「ダメージ分布」のグラフを、選んだ術耐性における物理化・術化の度数を比べるヒストグラムに変更した。表では引き続き全11条件の四分位数を表示する。

- 各条件で物理化と術化の両方を計算できた「通常攻撃型」のスキル段階を集計する。1段階につき、物理化と術化にそれぞれ1件を数える。
- 主攻撃1回のダメージを丸める前に500刻みで区切る。各階級は下限を含み上限を含まない。最後の階級には4,000以上をまとめる。対応防御力や有効な段階がない条件は「対象なし」とする。
- 下記の検証用データで属性限定効果を除外し、術耐性60・対応防御力1,200にすると、各属性の合計は552段階。500未満は物理化391段階、術化258段階、4,000以上はそれぞれ4段階と1段階になる。

## v2

属性限定効果をまとめて除外できるようにし、除外を仮想比較の初期条件にした。

- **除外**（`excludeAttributeEffects`）では、防御力・術耐性の無視と低下、片方の属性に限って適用される与ダメージ倍率・脆弱・術ダメージ固定加算などを除く。たとえば凍結した敵への攻撃では、術耐性低下を除いたうえで、凍結を条件とする両属性共通の効果を計算する。
- **適用**（`apply`）では、DC3で計算できる素質・スキル等の効果を通常どおり計算する。両設定に同じ敵ステータスとオペレーターの育成条件を使い、共通の攻撃力や倍率、ヒット数、最低保証などのダメージ規則を保つ。
- 主攻撃以外の追加攻撃や継続ダメージは従来どおり優勢率の対象外。弱点判定など、物理化と術化の両方で働く攻撃の仕組みは維持する。

## v1
