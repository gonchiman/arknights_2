# スキル別の物理・術ダメージの比較規則

「主攻撃の属性変更」と「術耐性別の統計」は、同じ防御力・術耐性の組で、主攻撃1回を物理化した値と術化した値を計算する。比較条件は両タブで共有する。「実際のダメージ内訳」は元の攻撃属性を使い、防御力・術耐性無視のチェックを独立して持つ。

## v3

「ダメージ分布」のグラフを、選んだ術耐性における物理化・術化の度数を比べるヒストグラムに変更した。表では引き続き全11条件の四分位数を表示する。

- 各条件で物理化と術化の両方を計算できた「通常攻撃型」のスキル段階を集計する。1段階につき、物理化と術化にそれぞれ1件を数える。
- 主攻撃1回のダメージを丸める前に500刻みで区切る。各階級は下限を含み上限を含まない。最後の階級には4,000以上をまとめる。対応防御力や有効な段階がない条件は「対象なし」とする。
- 下記の検証用データで属性限定効果を除外し、術耐性60・対応防御力1,200にすると、各属性の合計は552段階。500未満は物理化391段階、術化258段階、4,000以上はそれぞれ4段階と1段階になる。

## v2

属性限定効果をまとめて除外できるようにし、除外を仮想比較の初期条件にした。

- **除外**（`excludeAttributeEffects`）では、防御力・術耐性の無視と低下、片方の属性に限って適用される与ダメージ倍率・脆弱・術ダメージ固定加算などを除く。たとえば凍結した敵への攻撃では、術耐性低下を除いたうえで、凍結を条件とする両属性共通の効果を計算する。
- **適用**（`apply`）では、DC3で計算できる素質・スキル等の効果を通常どおり計算する。両設定に同じ敵ステータスとオペレーターの育成条件を使い、共通の攻撃力や倍率、ヒット数、最低保証などのダメージ規則を保つ。
- 主攻撃以外の追加攻撃や継続ダメージは従来どおり優勢率の対象外。弱点判定など、物理化と術化の両方で働く攻撃の仕組みは維持する。

## v1

初版のチェック項目は「防御力・術耐性無視を適用」で、初期状態はオン。オフでは無視だけを外し、耐性低下や属性限定の倍率を適用していた。変更前のコードは `6954aef7768fe954ec8c66a0090d6918e1bdb7b7`。この版のオンは `apply`、オフは `excludePenetration` を [順位別の計算](../../src/lib/damageThreeSkillRankMatrix.ts) または [統計](../../src/lib/damageThreeSkillRankStatistics.ts) に渡して再現できる。
