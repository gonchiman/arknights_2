# メインストーリーの出現敵一覧の画像出力

`#/analysis/enemies/main-spawns` の画面とPNGは、左端の「行番号」に絞り込み・並べ替え後の通し番号を表示する。未確定・未取得の状態行も数える。「画像を保存」で開くダイアログの初期範囲は、表示中のページの先頭行から最終行まで。開始行と終了行に指定した両端の行を含み、たとえば26〜28行目を出力すると、PNGの行番号も26、27、28と表示する。

[出現敵一覧](../../src/components/MainStoryEnemySpawnsPage.tsx)は、選択範囲の数値、列、並び順と、ステージ・敵名の絞り込みや表示形式などの条件を[共通の表画像ダイアログ](../../src/components/ComparisonTableImageDialog.tsx)に渡す。同じ表データをプレビューとPNGに使い、通常は出力用レイアウトを2倍に描画する。出力幅を指定した場合は、その幅を最終PNGの寸法として使う。縦横比や描画上限は[テーブル画像出力の共通仕様](../../instructions/shared/table-image.md)に従う。

「出力幅を1,920 pxに固定」は初期状態でオフ。オンにすると、全文・全行・全列が収まる出力用レイアウトを作り、タイトル・条件欄・文字を含む画像全体を同じ倍率で幅1,920 pxに合わせる。縦横比16:9では25行以上の表も全体を縮尺調整して1,920×1,080 pxで保存する。行数が多いほど出力後の文字は小さくなる。縦横比が「指定なし」の場合は、表全体の自然な比率から高さを求める。共通の辺・総画素数上限と、全文・全行・全列の保持を確認して保存する。既定のファイル名には `幅1920px` が入る。

HP・攻撃力・防御力・術耐性で並べ替えたときは、その順位を「行番号」の隣に出す。絞り込み後の値を使い、高い方を1位として同値は同順位にする。「1体ずつ」では1体、「体数をまとめる」ではステージごとの敵1行を1件と数える。値が未確認の行は「—」と表示する。昇降順や出力範囲を変えても、順位の計算対象は絞り込み後の全行となる。

保存画面の「ハイライト」では、通し行番号を `11,18-20` のように複数・範囲で指定し、表示中の全列から強調する列を選べる。順位列は、保存画面を開いたときの表にある場合に選べる。「選択した行・列を強調」は初期状態でオン、行と列は未選択。オフにすると選択を保持して強調の適用と行番号入力の検証を解除し、再びオンにすると復元する。出力範囲外の行番号や不正な入力はエラーにして保存を止める。

行と列は9%の帯、交差セルは18%の背景で強調し、罫線を維持する。強調対象もスナップショットに含め、プレビューとPNGで共有する。有効な強調対象は条件欄と既定のファイル名に記録する。

## 見本の再生成

0-1「崩落」の「1体ずつ」でHP列を降順にする。「画像を保存」で開始行を1、終了行を2、縦横比を16:9にし、「出力幅を1,920 pxに固定」をオンにして保存する。[見本PNG](examples/0-1-hp-desc-rows-1-2-16x9.png)は1,920 × 1,080 pxで、行番号1と2に兵士（HP1,650、1位）とオリジムシ（HP550、2位）を表示する。条件欄に集計版 v12、出力範囲とHPの並べ替えが入る。

章を「全章」、ステージを「全ステージ」、表示を「1体ずつ」、並べ替えを「ステージ 昇順」にする。「画像を保存」で開始行を1、終了行を25、縦横比を16:9にし、「出力幅を1,920 pxに固定」をオンにして保存する。[25行の見本PNG](examples/all-stages-rows-1-25-width1920-16x9.png)で、1,920×1,080 pxの画像に行番号1〜25と全列が収まることを確認する。

同じ全章・全ステージ・1体ずつ・ステージ昇順で、出力範囲を1〜25行にする。「ハイライト」の行番号に `11,18-20` を入力し、列の「防御力」と「術耐性」を選ぶ。縦横比16:9、「出力幅を1,920 pxに固定」をオンにして保存する。[行と列を強調した見本PNG](examples/highlight-rows-11-18-20-defense-resistance-1920-16x9.png)で、行番号11と18〜20、選択した2列、その交差セルを確認する。
