# メインストーリーの出現敵一覧の画像出力

`#/analysis/enemies/main-spawns` の「画像を保存」で、表示中のページの行範囲を初期値として指定できる。開始行と終了行は、保存画面を開いた時点の絞り込み・並べ替え後の表を1行目から数えた番号で、指定した両端の行を含む。未確定・未取得の状態行も元の表と同じ位置で数える。

[出現敵一覧](../../src/components/MainStoryEnemySpawnsPage.tsx)は、選択範囲の数値、列、並び順と、ステージ・敵名の絞り込みや表示形式などの条件を[共通の表画像ダイアログ](../../src/components/ComparisonTableImageDialog.tsx)に渡す。同じ表データをプレビューと2倍描画のPNGに使う。縦横比や描画上限は[テーブル画像出力の共通仕様](../../instructions/shared/table-image.md)に従う。

## 見本の再生成

0-1「崩落」の「1体ずつ」でHP列を降順にする。「画像を保存」で開始行を1、終了行を2、縦横比を16:9にして保存する。[見本PNG](examples/0-1-hp-desc-rows-1-2-16x9.png)は1,472×828 pxで、1行目がHP1,650の兵士、2行目がHP550のオリジムシになり、条件欄に出力範囲とHPの並べ替えが入る。
