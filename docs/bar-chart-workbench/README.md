# 共通の棒グラフ作成ページ

## 用途と適用範囲

`#/charts/bar` でデータの提供元を選ぶと、単系列の縦棒、左右2系列の横棒、または100%積み上げ横棒を表示してPNGに保存できる。タイトル、軸名、単位、条件は提供元が指定する。

[ページの標準構造](../page-layout/README.md)の単一出力を使う。データと集計条件は上段にまとめ、結果の操作列の右端に[画像保存とアドレスコピー](../page-layout/README.md#画像保存ボタン)を並べる。アドレスには表示中の図題を使う（例 `〈棒グラフ作成 / 属性別の優勢率〉`）。描画方式や棒幅などの自動設定、表示設定、強調はグラフの手前に置く。

敵データからはステータス分布、出現順位に基づく対応防御力、評価別比較、順位帯統計を選べる。DC3からは通常攻撃型スキルの属性別の優勢率を選べる。ステータス分布はHP、攻撃力、防御力、術耐性、移動速度、攻撃間隔、重量の数値階級に対応する。HP・攻撃力・防御力・術耐性にはゲーム内評価の階級と左右の評価別比較もある。順位帯統計は全体基準の標準化値から最小・最大・幅・平均・標準偏差・分散を選ぶ。

## 固定仕様と可変部分

### 提供元と共通描画の境界

提供元は、既存の計算処理を呼び出し、共通データへ変換する。共通描画は提供元の名前やページを判定して計算を切り替えない。タイトルや単位を、表示ラベルの文字列から推測しない。

| 提供元 | 既存の定義元 | 横軸と値の意味 |
| --- | --- | --- |
| 敵のステータス分布（`enemy-stat-histogram`） | [enemyStatMetrics.ts](../../src/lib/enemyStatMetrics.ts) / [buildEnemyHistogramObservations](../../src/lib/enemyHistogramCounts.ts) / [calculateWeightedHistogram](../../src/lib/enemyWeightedHistogram.ts) / [buildEnemyRatingHistogramBins](../../src/lib/enemyRatingHistogram.ts) | 選択ステータスの数値階級またはゲーム内評価の階級と、その階級に属する度数 |
| 防御力・術耐性の対応 | [buildEnemyDefenseResistanceBands](../../src/lib/enemyDefenseResistance.ts) の `resistanceThresholds` | 術耐性の下限を10刻みで取り、同じ出現順位の防御力を返す |
| 敵ステータスの評価別比較（`enemy-stat-rating-comparison`） | 既存の `enemy-stat-histogram` のゲーム内評価方式 | 左右で選んだステータスそれぞれの評価別度数・割合・累積割合 |
| 防御力・術耐性の順位帯統計（`enemy-rank-band-statistics`） | [buildStandardizedEnemyRankBandStatistics](../../src/lib/enemyRankBandStatistics.ts) | ステータスの高い順の順位帯と、帯内の最小・最大・幅・平均・標準偏差・分散から選んだ標準化統計量 |
| DC3 属性別の優勢率（`dc3-attribute-advantage`） | [DC3の術耐性別の統計](../../src/components/useDamageThreeSkillRankStatistics.ts)と[優勢率の内訳](../../src/lib/damageThreeAdvantageChart.ts) | 術耐性と対応防御力の組ごとに、物理・同じ・術の得票が占める割合 |

ステータス分布は `BarChartProviderContext.statKey` に [EnemyStatKey](../../src/lib/enemyStatMetrics.ts) の7種のキーを受け取る。省略時は `magicResistance`（術耐性）。旧提供元の `enemy-resistance-histogram` は `enemy-stat-histogram` に統合した。

数値階級の区切りは既存の敵統計と同じ線形計算を使う。術耐性は従来の階級幅10と最低上限100を維持し、他のステータスは共有定義の最小階級幅を渡して既存処理に自動計算させる。画面には計算結果の階級幅・通常階級の上限を表示し、幅や上限を手動で入力する設定は設けない。上限を超えた値は既存計算の上限超過階級に保持する。

### 数値階級とゲーム内評価の階級

`BarChartProviderContext.histogramBinning` は任意の `'numeric' | 'rating'` とし、省略時は `'numeric'`。HP、攻撃力、防御力、術耐性の分布だけに「階級：数値／ゲーム内評価」の選択を表示する。他の3種は数値階級だけを扱う。

`'rating'` は、数値階級の度数を足し合わせる方式ではない。[buildEnemyHistogramObservations](../../src/lib/enemyHistogramCounts.ts) が返す元の観測値・重みを [buildEnemyRatingHistogramBins](../../src/lib/enemyRatingHistogram.ts) に渡し、ゲーム内評価の正確な境界で直接集計する。EからSSまでの全評価を定義順に保ち、度数0の評価も省略しない。数値方式と同じ選択ステータス・範囲・重み・欠損除外を使い、割合と累積割合の分母も変えない。

ゲーム内評価の階級も数値区間として `xKind: 'interval'` を渡し、棒幅は区間型の96%を使う。下限なしの区間を表すため `BarChartInterval.start` は `null` も許容し、上限なしの `end: null` と区別する。上下の境界値と包含・除外の情報を保持し、表示された評価名から数値境界を復元しない。

横軸は、主段にE〜SSの評価、従段にその評価の数値範囲を配置する2段構成。提供元は `semantics.xQualifier`・`semantics.xBandTitle` に軸と帯の意味を、任意の `document.secondaryAxisBand` に `title` と主段の各列に対応する `labels` 配列を渡す。描画側はこれらの共通データを使い、敵・ステータス・提供元の名前を判定して帯を作り分けない。

範囲の表示には既存の [formatHistogramRatingRangeLines](../../src/lib/histogramRatingRangeStrip.ts) の簡略表記を使う。正確な境界の包含・除外は `interval` のメタデータと読み上げ用の説明に保持する。`settings.axisBand` がオンのときは評価と範囲の両段を帯で表示し、オフのときは評価名の目盛りだけを残して範囲段を表示しない。

数値階級に添える評価帯と、ゲーム内評価そのものを階級にする方式は別の機能。ゲーム内評価方式では `capabilities.rankBands` を `false` とし、評価帯の設定が残っていても同じ評価を重ねて表示しない。

### DC3 属性別の優勢率

「データ」で「DC3 属性別の優勢率」を選ぶとスキルを読み込む。集計版・範囲は敵統計と共通で、初期条件はメインストーリー・スキル単位・属性限定効果を除外。対象はDC3の通常攻撃型。スキル単位では1スキルの1票を有効な段階の結果に応じて按分し、段階単位では各有効段階を1票とする。単位を切り替えると同じ集計から表示を更新する。

共通部品 [BarChartStackedPlot](../../src/components/BarChartStackedPlot.tsx) は `layout: 'stacked-percent'` の `stack` から列名、凡例、行ごとの見出し・有効数・得票を受け取る。行ごとの有効数を100%とし、各区分の生の票数を同じ軸で描画する。術耐性は各行の条件を示す点型とし、棒の厚さは1行の60%（最大48px）。全票同点は灰色の100%、比較対象のない条件は「対象なし」と表示する。行の強調はチェックボックスと行クリックで共有し、保存した画像にも反映する。

術耐性・対応防御力・有効数の3列には、左右比較と共通の [ChartStripRowCell](../../src/components/ChartStripCell.tsx) を使う。数値は淡い灰色のセルに中央揃えで表示し、セル間の余白で行を区切る。横軸は単体グラフの割合軸と同じ25ポイント刻み。0%を基線にして、棒の領域には割合の縦線を引く。強調時は選択した術耐性セルの背景を濃くし、その行のラベルを太字にして、他行の棒を薄くする。

### 共通データ契約

対応データは[対応表のページ](../../src/components/EnemyDefenseResistancePage.tsx)の計算結果を使う。[対応式のページ](../../src/components/EnemyDefenseResistanceFormulaPage.tsx)の回帰・近似式とは別の入力である。防御力と術耐性の両方が有効な敵を、出現回数で重み付けする。

データ契約では、数値の点、端点を持つ区間、順序を持つカテゴリを区別する。区間は上下の端点・端点を含むか・上限超過を保持し、表示済みの「0〜10」から復元しない。区間端点の `null` は境界なしを表し、棒の値の `null` は欠損を表す。値は丸める前の数値とし、0は有効な値として扱う。出現回数は期待値の小数を含み得るため、度数を整数に限定しない。

`BarChartDocument` はJSONで受け渡せる、元の入力から切り離した固定スナップショット。`bins` に階級・点・値を、`semantics` にラベルの意味を、`source` に提供元・集計版・範囲・集計方法・母集団・欠損・収録状況を保存する。横軸の単位は任意の `semantics.xUnit` に渡す。攻撃間隔は `xLabel: '攻撃間隔'` と `xUnit: '秒'` から「攻撃間隔（階級・秒）」を生成し、単位を含む表示済みラベルを分解しない。表示ラベルは共通の `getBarChartLabels` と `getBarChartConditions` で作る。描画関数、JSX、DOM参照、ページの状態をデータへ含めない。

左右比較では `layout: 'mirrored'`、`xKind: 'category'`、`semantics.kind: 'comparison'` とする。ルートの `bins` は共通のカテゴリIDとラベルを保持し、値は `null`。棒を並べる項目の意味は `semantics.itemKind: 'interval'` で別に宣言する。`series` は左・右の順の2要素で、固定ID `left`／`right`、ラベル、選択キー、カテゴリ順に揃った `bins`、個別の `population` を持つ。評価別比較の各系列には元の度数・正の割合・累積割合・正確な数値境界を、順位帯統計には選択した統計量の標準化値を保持する。ルートの `source.population` は `null` とし、共通の割合の分母を示さない。左へ伸ばすために入力値を負数へ変換せず、標準化平均などの実際の負値は符号を保つ。

左右配置で何を棒の長さにするかは `semantics.comparisonValue: 'share' | 'value'` で宣言する。省略時は従来どおり `share` とし、系列の `bins[].share` を割合として使う。`value` は `bins[].value` の値を直接使い、100倍や割合への換算を行わない。`semantics.comparisonLabel` はタイトル末尾の名称で、省略時の「評価別分布」に代わる「順位帯別標準偏差」などを提供元から渡す。描画側が提供元名で分岐しない。

### 左右2系列の評価別比較

「敵ステータスの評価別比較」では、HP・攻撃力・防御力・術耐性から左右を個別に選ぶ。APIの `leftStatKey`・`rightStatKey` を省略した初期値は防御力／術耐性。同じステータスを左右に指定しても2系列を保持し、入れ替えた場合は比較順序をタイトル・条件・保存名へ反映する。

提供元は、既存のゲーム内評価ヒストグラムを各ステータスへ独立に適用する。E〜SSの全10評価と度数0を残し、それぞれの有効度数を割合・累積割合の分母にする。両方が有効な敵だけへ絞らず、2系列の母数も合算しない。条件には左右ごとの有効数と値なしを表示する。

`getBarChartComparisonAxis` が両系列の階級割合からゼロ始まりの共通軸を作り、同じ割合は左右で同じ長さになる。色は各 `series.metricKey` と[ステータス指標の共通配色](../stat-metric-colors/README.md)で決める。防御力は青、術耐性はオレンジとし、左右を入れ替えても指標の色を維持する。同じ指標を左右に選んだ場合も同じ色を使い、直接ラベルと位置で識別する。棒の太さは [barChartPresentation.ts](../../src/lib/barChartPresentation.ts) の区間型の共通定義を使い、1評価の高さの96%とする。横棒であることを理由とする別の棒幅は設けない。画面の自動設定も同じ定義から「左右の横棒・区間型」、棒幅、系列数、共通目盛りを表示する。隙間の使い分けは、下記の[棒間の隙間を決める基準](#棒間の隙間を決める基準)で定める。

外側の帯は任意設定 `comparisonBand: 'cumulative' | 'rank' | 'none'` で切り替え、省略時は累積割合。中央の評価と外側の数値は `ChartStripCell` を再利用し、共通の11px書式、背景不透明度6%、行の間隔3pxで揃える。`0`、極小の正値 `<0.1`、母数なし `—` を区別する。

共通の強調設定で評価を選ぶと、`getBarChartSelectionSummary` が元の度数を合算して各系列の有効度数で割る。丸めた割合は足し合わせず、有効度数0は合計割合も `null` とする。連続する選択は「E〜C」のようにまとめて表示する。

画面・保存プレビュー・PNGは同じ `BarChartPlot` から左右配置の描画へ渡す。自然な高さは [barChartLayout.ts](../../src/lib/barChartLayout.ts) の見出し・行・選択合計の共通定義から求め、合計欄の追加で棒を縮めない。保存開始時に系列データと選択配列も固定する。PNGの幅と比率、保存操作は既存の共通出力を使う。保存名は左右の順序、集計条件、帯の種類、強調する評価、比率を識別し、単系列用の持ち越し設定を含めない。

### 防御力・術耐性の順位帯統計

提供元 `enemy-rank-band-statistics` は、「防御力と術耐性の対応 → 順位帯の統計 → 表」と同じ [buildStandardizedEnemyRankBandStatistics](../../src/lib/enemyRankBandStatistics.ts) の結果を共通データへ変換する。データは順位帯の統計であり、標準偏差はグラフに使う統計量の1つとして選択する。集計対象は防御力と術耐性の両方が有効な出現、集計方法は出現回数。`BarChartProviderContext.rankBandStep` は `5 | 10 | 20` ポイント、初期値は10。順位はステータスの高い順とし、それぞれの指標を独立に並べる。集計版・全体／メインストーリーの範囲は共通設定から渡す。

`rankBandMetric` は `keyof EnemyRankBandStatValues` の `min | max | width | mean | standardDeviation | variance`、初期値は `standardDeviation`。画面の「統計量」で表と同じ6種から選ぶ。名称は [enemyRankBandStatisticsDisplay.ts](../../src/lib/enemyRankBandStatisticsDisplay.ts) の共通定義を使う。幅は帯内の最大−最小。平均、標準偏差、分散も既存の出現回数による重み付き計算を使い、分散は母分散とする。同じ値の全出現回数を各帯へ重複して入れず、その順位帯と重なる出現重みだけを使う。

尺度は元の表と同じ全体基準の標準化に固定する。標準化の基準となる全体平均μ・母標準偏差σは、選択中の集計版・範囲で両ステータスが有効な集合から指標ごとに求める。最小・最大・平均は `(値−μ)/σ`、幅・標準偏差は `値/σ`、分散は `値/σ²`。帯ごとに基準を求め直したり、標本分散へ置き換えたりしない。

`semantics.comparisonValue: 'value'` とし、`comparisonLabel` と `semantics.xLabel` に選択した統計量の名称を渡す。タイトル・軸名・外側の帯の見出しは同じ選択から自動生成する。`xQualifier: '標準化'` から「平均（標準化）」などの軸名を生成し、元のステータスの単位や `%` を付けない。分散を標準偏差と同じ値・名称で扱わない。

2系列は既存の左右配置の共通描画へ渡す。左右・全順位帯に同じ数値範囲を使い、同じ絶対値を同じ棒の長さで表す。非負の統計量はゼロ始まりの共通軸。標準化平均などに負値がある場合は両側に同じ負領域を確保し、各トラック内の0の基線から符号に沿って描く。絶対値へ置き換えて符号を消さず、目盛り・帯・直接表示にも元の符号を保持する。順位帯は連続する数値範囲なので `semantics.itemKind: 'interval'` とし、区間型の共通棒幅を使う。色はそれぞれの `series.metricKey` から共通の指標色を取得し、負値でも統計量を変えても指標色を維持する。

外側の帯は `comparisonBand: 'value' | 'none'` の数値／なしだけを使う。評価別比較の割合・累積割合の設定が残っていても統計量から割合を作らない。`selectedRanks` のカテゴリIDによる複数行の強調はできるが、統計量の選択合計は定義せず、合計欄もその予約高も追加しない。

帯内が同値で、全体の標準偏差は有効な場合の幅・標準偏差・分散0は、真の0として保持する。全体の標準偏差が0などで標準化できない系列は `null` とし、棒を描かず「—」で表す。0に置き換えず、もう一方の有効な系列は表示する。

保存する固定スナップショットには値、順位帯、指標ID、比較値の方式、統計量、見出し、集計版・範囲・出現回数・順位帯幅・全体基準の標準化の条件を保持する。標準偏差・分散では母分散も条件に保持する。条件と保存名も同じデータから生成し、統計量・帯の表示・強調・幅・比率を実際の表示状態に合わせる。共通有効集合の件数・欠損は条件欄へ1回だけ示す。旧ページの表とグラフは引き続き使い、この提供元への置換は行わない。

### 画像一括出力

「画像を保存」の初期対象は「現在の条件」とし、従来の1枚のPNGを保存する。「複数条件」では、提供元が用意した以下の一覧から出力対象を複数選択する。全項目のチェックは初期ON。選択が空なら保存できず、1条件ならPNG、2条件以上ならZIPを使う。「PNGをフォルダへ」も既存の保存UIから選べ、非対応のブラウザーでは無効にする。現在のグラフに一致する条件が一覧にあれば、その条件を最初のプレビューにする。プレビューを切り替えても、選択した出力枚数や条件は変えない。

提供する候補が7条件以上の出力一覧には「全選択」「すべて解除」を置く。プレビューの選択は、提供する候補が6条件以下なら既存の条件ボタン、7条件以上ならプルダウンを使う。保存対象としてチェックした条件だけをプレビューに並べる。

| 提供元・階級方式 | 複数選択する条件 | 固定する主な条件 |
| --- | --- | --- |
| 敵のステータス分布・数値階級 | 7ステータス | 集計版・集計範囲・集計方法・数値階級方式 |
| 敵のステータス分布・ゲーム内評価 | HP・攻撃力・防御力・術耐性の4ステータス | 集計版・集計範囲・集計方法・ゲーム内評価方式 |
| 敵ステータスの評価別比較 | 「組み合わせ」の一覧から、4ステータスの左右16通り | 集計版・集計範囲・集計方法・外側の帯・行の強調 |
| 防御力と術耐性の対応 | 全体・メインストーリーの2集計範囲 | 集計版・出現回数・術耐性の10刻み |
| 防御力・術耐性の順位帯統計 | 最小・最大・幅・平均・標準偏差・分散の6統計量 | 集計版・集計範囲・出現回数・順位帯幅・外側の帯・行の強調 |
| DC3 属性別の優勢率 | スキル単位・段階単位 | 集計版・集計範囲・属性限定効果・通常攻撃型・行の強調 |

左右の組み合わせは順序を区別し、同じステータス同士も一覧に残す。「防御力と術耐性の対応」の複数条件は、選択中の集計版に全体・メインストーリー両方の出現回数がある場合だけ表示する。利用できない版のデータを現在のデータから補わず、「現在の条件」による1枚の保存を保つ。

提供元の `createBarChartProviderVariants` が、保存画面を開いた時点の同じデータと設定から、条件別の固定データを作る。保存側はステータスの度数や順位帯の統計量を計算し直さない。順位帯幅の複数選択は追加せず、画面で選択中の幅を使う。分布の数値階級幅と上限は、各ステータスの既存の自動計算を維持する。割合・累積割合・評価帯などの表示設定は共有するが、対象のデータで有効なものだけを描画・命名に使う。

一括出力にも同じ `BarChartPlot`・`ChartImageFrame` を使い、幅1,920pxと保存画面で選んだ縦横比を各PNGへ適用する。各PNGの名前は条件ごとのステータス・左右の組み合わせ・集計範囲・統計量と、有効な主要条件・表示・比率を識別する。ZIP名は提供元の表示名・選択した条件・枚数と共通条件を識別し、1枚目に固有のステータスや集計範囲を全画像の条件として扱わない。階級方式は「数値階級」「ゲーム内評価」で区別し、評価別比較の16通りすべてを選んだ場合は「全組み合わせ」と示す。手入力名はZIPまたは単独PNGへ使い、フォルダ保存では条件別の自動名を使う。

ZIP・フォルダ保存の進捗、保存先の取消し、同名ファイルの回避、フォルダへの書き込み失敗後の再試行は既存の共通処理を再利用する。全PNGが生成できてからZIP作成・フォルダ書き込みを始める。途中で書き込みに失敗した場合は保存済み枚数を表示し、同じ条件なら未保存分から続ける。出力対象・保存方式・選択条件・比率を変更した場合は再開状態を破棄し、プレビューだけの切り替えでは破棄しない。

### 割合と累積割合

割合・累積割合は度数データだけに提供する。分母は欠損を除いた有効な重みの合計。元の度数と同じ階級順で[buildHistogramCumulativeRows](../../src/lib/histogramCumulative.ts)を利用し、各階級の割合と、その階級全体までの累積割合を保持する。棒の中央の数値で読み取ったECDFに置き換えない。

有効な分母がない場合、割合は`null`にする。防御力の対応値は度数ではないため、値を足し合わせて割合や累積割合を作らない。表示設定に値が残っていても、対応していない情報帯は描画しない。

累積割合は、既存の線と、新たな帯を独立して表示できる。線の設定キーは従来どおり `cumulative`、画面の表示名は「累積割合線」とする。帯は任意の `cumulativeBand` で指定し、省略時・初期値は `false`。線をオフにして帯だけを表示する場合も、同じ `bins[].cumulativeShare` を使う。

### 評価帯

評価帯はHP、攻撃力、防御力、術耐性の4種の数値階級の分布に提供する。ゲーム内評価方式では主段と重複するため提供しない。移動速度、攻撃間隔、重量、および防御力と術耐性の対応グラフにも提供しない。

提供元で、表示ラベルへ変換する前の `HistogramBin[]` から [getHistogramStatRankBands](../../src/lib/histogramStatRankBands.ts) を呼び出し、結果を任意の `BarChartDocument.rankBands?: StatRankBand[]` に保存する。提供できるかどうかは任意の `capabilities.rankBands?: boolean` で表す。描画側はステータス名や表示済みの階級文字列から評価を推定せず、スナップショットに含まれる帯データだけを使う。

表示設定は任意の `rankBand`、省略時・初期値は `false`。評価定義のある数値階級の分布だけに「評価帯」の選択肢を表示し、ゲーム内評価方式や別の提供元、未対応ステータスへ設定を持ち越しても帯を描画しない。数値階級を分割・変更せず、その階級に対する既存の評価境界と上限超過の扱いを引き継ぐ。

### 棒間の隙間を決める基準

隙間を小さくするかどうかは、棒を並べる軸が「連続する数値範囲を区切った階級」か「個別の比較項目」かで決める。縦棒では横軸、横棒では縦軸に同じ基準を適用する。度数・割合・DPSなど、棒の長さを表す数値軸では判定しない。

| 棒を並べる軸の意味 | 例 | 棒間の隙間 |
| --- | --- | --- |
| 連続する数値範囲を区切った階級 | 術耐性0〜10、10〜20、ステータス順位帯の上位0〜10% | 小さくする |
| 個別に指定した数値の点 | 術耐性0・20・50でのDPS、術耐性の下限に対応する防御力 | 通常の隙間を空ける |
| 独立したカテゴリ | OP名、職業、MOD | 通常の隙間を空ける |

数値ラベルか文字ラベルか、あるいは表示名の並び順だけでは判断しない。敵ステータスのゲーム内評価E〜SSは元の数値範囲を区切った階級なので、数値階級と同じく隙間を小さくする対象とする。単体の分布と左右比較でこの判断を変えず、系列数や情報帯の有無も分類の根拠にしない。

左右比較の `xKind: 'category'` は、2系列の共通カテゴリを整列させるデータ構造を表す。元の評価を独立したカテゴリへ変更する指定ではない。提供元は、各系列の評価が数値範囲の階級であることを `semantics.itemKind: 'interval'` で宣言する。描画側はラベルや系列名、境界の見た目から意味を推測しない。

`semantics.itemKind` は任意の `'interval' | 'point' | 'category'`。共通の `getBarChartItemKind(document)` がこの宣言を優先し、省略時は従来の `xKind` を使う。数値階級とゲーム内評価は `interval`、個別に指定した点は `point`、独立した比較項目は `category` とする。描画方向の `layout` は配置を決め、項目の意味や棒幅の規則を上書きしない。

この基準は隙間の使い分けを定める。具体的な比率・上限は [barChartPresentation.ts](../../src/lib/barChartPresentation.ts) の共通定義で管理し、提供元やページごとに独自の寸法を追加しない。

### 強調

グラフの列・行をクリックするか、グラフの上の「強調」で、階級・評価・順位帯・術耐性の下限を複数選べる。同じ区画を再度クリックすると解除する。左右の横棒は左・右を個別に選べる。中央の項目名をクリックすると同じ項目の両側を選択し、両側とも選択済みなら解除する。チェック欄にも「両側」「左」「右」の切り替えを用意する。「すべて解除」でデータ切り替え前に保持した選択も含めて強調を解除する。集計条件や表示設定は保持する。初期値は選択なし。選択中の棒は各指標の通常色を保ち、ほかの棒の不透明度を44%にする。数値ラベルや補助線は通常の書式で表示する。縦棒は階級名に淡い指標色、左右の横棒では中央セル全体を、両側選択なら淡い中性色、片側選択ならその指標の淡い色で表示する。選択中の項目名は太字で、横軸の帯をオフにしても強調した階級名の背景は表示する。度数0や欠損でも項目名で選択を確認できる。画面と保存の描画は同じ選択を使う。

共通設定 `selectedRanks` は `bins[].id` の配列で、描画するグラフに含まれるIDだけを使う。左右比較で片側だけを強調するIDは `comparisonSelection` の左右それぞれに保持する。選択合計は左右それぞれが選んだ評価から計算する。ゲーム内評価のIDは単体分布と評価別比較で共有する。数値階級のIDはステータスと境界を含み、別の指標の階級へは引き継がない。1枚ずつのPNG名にはその画像で強調する項目を入れ、左右の選択が異なる場合は左・右を記載する。ZIP名には全画像で共通する強調項目を入れる。

### 共通表示

単体の指標色は `document.semantics.metricKey` から、比較の指標色は各 `series.metricKey` から取得する。提供元が固定スナップショットへキーを保持し、描画側はタイトル・表示名・系列順から色を推測しない。通常の棒の不透明度と、累積割合線・点・右軸名の濃灰および破線は、[statMetricColors.ts](../../src/lib/statMetricColors.ts) の共通定義を使う。キーの省略・未知のキー・派生指標は中性色とする。

数値書式、情報帯、見出しと条件の配置は共通にする。単系列では縦棒とゼロを含む縦軸を使い、左右比較では上記の配置を使う。画面のグラフ内の操作は列・行の強調のみにする。保存プレビューは保存時点の表示設定を描画する。その他の操作はグラフの外に置き、狭い画面ではラベルを読める横幅を保って横スクロールする。

情報帯は、表示を有効にしたものだけを上から「累積割合帯 → 割合帯 → グラフ → 階級帯 → 評価帯」の順に置く。累積割合線はグラフ内に重ね、帯の表示とは連動させない。評価帯は [StatRankStrip](../../src/components/StatRankStrip.tsx)、各セルは [ChartStripCell](../../src/components/ChartStripCell.tsx) を再利用する。文字は回転させず、帯にもツールチップやホバー操作を追加しない。

ゲーム内評価方式の横軸は「評価の主段 → 範囲の従段」とし、数値方式で使う注釈の評価帯をさらに追加しない。

自然なグラフ高は [getBarChartNaturalHeight](../../src/lib/barChartLayout.ts) で求め、画面とPNGで同じ値を使う。単系列の縦棒は従来の334pxに、有効な累積割合帯・評価帯それぞれの28pxを加える。横軸の範囲段が有効な場合は基準高38pxと段間4pxの計42pxも加える。範囲は狭い幅で実際の文字幅に合わせて横書きで折り返し、必要な高さを確保する。追加した帯がオフ、または提供元が未対応の場合はその帯の高さを増やさず、数値階級の既存表示の高さを維持する。

描画方式と棒幅は `getBarChartItemKind(document)` が返す項目の意味と [barChartPresentation.ts](../../src/lib/barChartPresentation.ts) の共通定義で決める。画面の「自動設定」も同じ定義から描画方式・棒幅・上限を表示し、提供元名や値の大小、0や欠損から型を推定しない。区間型は1項目の区画の96%、点型とカテゴリ型は60%で上限48px。区画は縦棒では描画領域の幅を、横棒では高さを**すべてのbins**で割った大きさであり、0や欠損の項目も含む。48pxは**PNG拡大前のCSS/SVG座標**で、保存画像の1,920pxへの拡大率を掛ける前の値。画面とPNGで別の棒幅を定義しない。

利用ごとに変更するのは提供元、ステータス、階級方式、順位帯幅、統計量、集計版、集計範囲、表示設定。「敵のステータス分布」では単体のステータス選択、「敵ステータスの評価別比較」では左右の選択、順位帯統計では「順位帯幅」「統計量」を表示する。単系列の表示設定は `values`（棒の値）、`axisBand`（横軸の帯。ゲーム内評価方式では評価・範囲の2段）、`percent`（割合帯）、`cumulative`（累積割合線）、任意の `cumulativeBand`（累積割合帯）・`rankBand`（評価帯）。追加した2項目は初期値 `false` とし、従来の4項目だけを持つ設定も表示を変えずに扱う。提供元の能力に合わない設定は無効化する。コード上の既定値と各寸法は共通部品・定義を正とし、別のページへコピーしない。画面の初期集計は数値階級・術耐性・最新版・メインストーリー・出現回数。対応値と順位帯統計の提供元は出現回数だけを使う。

画面・保存プレビュー・PNGには同じデータと設定を渡す。評価帯・従段の範囲・階級方式のデータも固定スナップショットへ含め、保存ダイアログを開いた後の編集で、既に開いているプレビューの計算結果や帯を差し替えない。PNGの幅は1,920px、保存ダイアログの初期比率は16:9とし、自動比率とカスタム比率も共通の保存UIから選べる。設定を識別する保存名は `getBarChartFilename` で生成し、ゲーム内評価の階級方式や、有効にした累積割合帯・評価帯も識別する。未対応の提供元やゲーム内評価方式で残った設定など、実際に表示しない割合・評価帯を名前に含めない。

## 使い方

提供元の登録と変換処理には `BAR_CHART_PROVIDERS` と `createBarChartFromProvider` を使う。以下の `data` と `version` は、既存の敵集計クライアントで読み込んだ同じ版のデータと版情報。

```tsx
const document = createBarChartFromProvider('enemy-stat-histogram', {
  data,
  version,
  scope: 'main',
  countMode: 'SPAWNS',
  statKey: 'defense',
  histogramBinning: 'numeric',
})

<BarChartFigure document={document} settings={{
  values: true,
  axisBand: true,
  percent: true,
  cumulative: true,
  cumulativeBand: true,
  rankBand: true,
}} />
```

ゲーム内評価の階級を作る場合は、同じ呼び出しで `histogramBinning: 'rating'` を指定する。`statKey` はHP・攻撃力・防御力・術耐性のいずれかとし、表示には通常の `BarChartFigure` と同じ設定を渡す。この方式では `rankBand: true` が残っていても評価帯は表示しない。

左右比較も同じ描画の入口へ渡す。

```tsx
const comparison = createBarChartFromProvider('enemy-stat-rating-comparison', {
  data, version, scope: 'main', countMode: 'SPAWNS',
  leftStatKey: 'maxHp', rightStatKey: 'attack',
})

<BarChartFigure document={comparison} settings={{
  ...DEFAULT_BAR_CHART_DISPLAY_SETTINGS,
  comparisonBand: 'cumulative',
  selectedRanks: ['rating-E', 'rating-D'],
}} />
```

`DEFAULT_BAR_CHART_DISPLAY_SETTINGS` は [barChartDocument.ts](../../src/lib/barChartDocument.ts) から読み込む。集計版・集計範囲・出現回数は既存の共通設定を使い、ステータスの選択によって母数を共通化しない。

順位帯統計も同じ描画へ渡す。提供元が既存の表と同じ標準化計算を呼び出し、`rankBandMetric` でグラフに使う統計量を選ぶ。利用側や共通描画で統計量や割合を計算し直さない。

```tsx
const rankBandStatistics = createBarChartFromProvider('enemy-rank-band-statistics', {
  data, version, scope: 'all', countMode: 'SPAWNS', rankBandStep: 10,
  rankBandMetric: 'standardDeviation',
})

<BarChartFigure document={rankBandStatistics} settings={{
  ...DEFAULT_BAR_CHART_DISPLAY_SETTINGS,
  comparisonBand: 'value',
}} />
```

提供元を追加するときは、提供元一覧へ変換処理を登録し、タイトル・軸・単位・集計条件・対応可能な表示をデータに含める。共通描画はレイアウトとデータの意味に従う。複数系列が同じ母数の内訳を構成する場合は100%積み上げ横棒を利用できる。

## 適用状況

共通ページ `#/charts/bar` の7ステータスの数値階級の分布、4ステータスのゲーム内評価の分布、防御力と術耐性の対応、4ステータスの左右評価別比較、防御力・術耐性の順位帯統計と、そのページのPNG出力へ適用する。数値階級に添える4種の評価帯も引き続き利用できる。既存の敵分布はステータス定義と指標の配色を共有するが、グラフ自体は共通描画へ未移行。配色の適用先は[ステータス指標の共通配色](../stat-metric-colors/README.md)を参照し、集計・階級・棒幅・初期値などは維持する。対応表・対応式、DC3、GG、スルトの出力を一括変更しない。旧ページの順位帯統計も残し、同じ表の計算結果にある6種の統計量を共通描画へ渡す。

棒間の隙間を軸の意味で判断する基準は、本仕様の「棒間の隙間を決める基準」で定める。単系列の数値階級・ゲーム内評価と、左右評価別比較のE〜SSに同じ区間型の棒幅を適用する。左右比較の確認用PNGも、この共通定義による見本とする。適用範囲は共通の棒グラフ作成ページであり、既存の敵統計ページにある評価別分布など、別の描画部品は移行しない。

## 変更時の確認

- 棒を並べる軸の意味で隙間を判定し、数値階級・ゲーム内評価の階級、個別に指定した点、独立したカテゴリを区別する。縦棒・横棒、数値・文字ラベルの違いで判定を変えない。
- 左右比較の `xKind: 'category'` と `semantics.itemKind: 'interval'` を区別し、全16通りで区間型の棒幅を使う。項目の意味を固定スナップショットへ保持し、画面・保存プレビュー・PNGの棒幅と自動設定を一致させる。
- 同じ版・範囲・提供元・ステータス・階級方式は同じタイトル、軸名、値、並び順を返す。
- 7ステータスについて、v12メインストーリーの出現回数で既存計算の度数・欠損・階級幅・上限と一致する。術耐性の既存幅10と、防御力の対応値も維持する。
- ゲーム内評価方式は元の観測値から集計し、数値階級を合算しない。4種のE〜SS全評価・境界の包含と除外・下限なしと上限なし・度数0を保持する。
- ゲーム内評価方式の主段は評価、従段は範囲とし、横軸の帯をオフにした場合は評価の目盛りだけを表示する。狭い幅でも範囲は回転させず、横書きで折り返す。
- 自動設定に計算済みの階級幅・上限が表示され、対応値の提供元ではステータス選択と階級設定が表示されない。
- 攻撃間隔の横軸は秒を含み、単位や括弧を重複させない。
- 0と欠損、空データ、有効な分母0、全値0、端点と上限超過を区別する。
- 度数以外の値には、割合・累積割合の設定を持ち越しても表示しない。
- 累積割合線と累積割合帯を個別に切り替え、同時表示した場合も同じ累積値を示す。
- 評価帯はHP・攻撃力・防御力・術耐性の数値階級だけに表示し、元の階級・端点・上限超過の意味を保つ。ゲーム内評価方式、未対応ステータス、対応値グラフへ切り替えたときは表示・保存名へ含めない。
- 追加した帯データ・設定を固定スナップショットへ保持し、後の選択変更が開いている保存プレビューへ影響しない。
- 追加帯の数に応じた自然な高さを画面・プレビュー・PNGで共有し、帯がオフのときは従来の高さを維持する。
- 画面・プレビュー・PNGは同じ値、ラベル、設定を保ち、計算結果を変更しない。縦棒の数値階級・ゲーム内評価・術耐性の下限と、左右の横棒で複数強調と解除を確認する。選択中の棒とラベルは読みやすさを保ち、周囲の棒だけが淡くなる。度数0と欠損は項目名の背景で強調が分かる。
- 指標色と通常の棒の不透明度が単体・比較で一致し、左右を入れ替えても色は指標に対応する。累積割合線・点・右軸名は共通の濃灰、線は共通の破線を使う。
- 左右比較の全16通りで既存の単体評価ヒストグラムと度数・個別母数・境界が一致する。同一ステータスでも2系列を残す。
- 左右比較は同じ割合を同じ棒の長さにし、外側の帯3形式、複数評価の強調、元の度数からの選択合計、母数0の欠損表示を保つ。
- 左右の順序・有効な帯・強調が保存名に反映され、単系列用の持ち越し設定は含まれない。選択配列も保存スナップショットから切り離される。
- 順位帯統計は6種の統計量、5・10・20ポイント刻み、両集計範囲で既存の表の標準化計算と一致し、同値の重みを各帯へ重複して入れない。帯内と全体で母分散を使い、全体基準を帯ごとに作り直さない。
- 値の左右比較は生の `value` を共通軸へ直接描き、標準化した平均・最小・最大の負値と、各トラックの0の基線を保持する。同じ絶対値は左右同じ長さになる。非負の統計量と従来の評価別割合はゼロ始まりの軸を維持する。
- 外側は数値／なしだけ、割合・累積割合・統計量の選択合計を表示しない。行の強調による高さの増加や無効設定の保存名への混入がない。
- 真の0、空データ、全体の標準偏差0などによる標準化不能を区別する。比較値の方式・統計量・順位帯幅・全体基準の標準化・該当する母分散・集計条件を固定スナップショットと条件・保存名へ保持する。
- 一括出力は数値分布7種・評価分布4種・左右評価比較16通り・対応値の2集計範囲・順位帯の6統計量を、元の単独保存と同じ値・PNGで出力する。左右同一・入替も別条件として保持し、対応値の本編出現回数がない版では複数条件を表示しない。
- 保存画面を開いた後の元データ・表示の変更やプレビューの切替えが、固定済みの出力集合へ影響しない。出力対象0・1・複数、選択順・重複・不明キーを扱い、保存名・枚数・実際に有効な表示設定を一致させる。ZIP名へ1条件に固有の情報を共通条件として混入させない。
