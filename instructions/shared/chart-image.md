# グラフ画像出力の仕様

このプロジェクトでグラフの画像出力を作成・変更するときに適用する。画面上のグラフ、表だけの画像、スライド画像は対象外とする。実在する共通部品、見本、適用状況は利用側の仕様に記載する。

## 配置

- 凡例は左、タイトルは中央、主要条件は右に置き、同じヘッダー行にまとめる。
- タイトルは画像全体の中央に置く。左右の領域は同じ幅にし、凡例や条件の文字量でタイトルをずらさない。タイトル領域の上限は内幅の44%とする。
- 凡例がない場合も左側の領域を保ち、タイトルを中央に置く。
- 凡例や条件が長い場合は、それぞれの領域内で折り返し、必要なヘッダーの高さを確保する。凡例を収めるためだけに画像幅を広げたり、タイトルの下に専用の行を追加したりしない。
- 右上の条件は、期間や対象など図を理解するための主要条件に絞る。設定をすべて列挙しない。集計済みの結果と一致する条件を使う。
- 横軸名はグラフの下に中央配置する。縦軸名と目盛りは各グラフ内で描画する。
- 特定の線を示す名称と値は線の近くに直接表示できる。直接ラベルで識別できる場合は、同じ説明の凡例を重ねて設けない。
- 枠組みの共通化を理由に、グラフの計算結果、ラベルの意味、色や線種を変えない。
- 系列の色は利用側の共通配色定義に従い、画面・凡例・プレビュー・保存画像で統一する。

## サイズと文字

単位はPNG化する前のCSSピクセル。PNGの倍率は保存処理側で管理する。

| 項目 | 標準値 |
| --- | --- |
| 基準の画像幅 | 960px |
| 外側の余白 | 上下12px、左右16px |
| ヘッダー・フッター・外側余白を合わせた最小予約高 | 76px。実際の高さに応じて拡張 |
| ヘッダーの列間隔 | 18px |
| タイトル | 17px、行高22px、太字 |
| 凡例 | 10px、行高18px |
| 凡例の項目間隔 | 横10px、折り返し時の縦6px |
| 凡例の線見本 | 幅18px、高さ12px、線幅2px。色と線種は系列と一致 |
| 凡例の記号と文字の間隔 | 5px |
| 条件 | 11px、行高18px、文字色 `#666` |
| 目盛り | 11px、文字色 `#555`、等幅数字 |
| 縦軸名 | 12px、太字、文字色 `#444` |
| 横軸名 | 12px、行高18px、太字、上余白12px |
| 背景 | 白 |
| フォント | Yu Gothic、YuGothic、Hiragino Kaku Gothic ProN、system-ui、sans-serif |

- グラフ領域の自然な高さは、必要なラベル数やグラフ種類に応じて決める。特定グラフの高さを、すべてのグラフに固定適用しない。
- 比率の指定なしでは、幅960pxと自然な高さを基準にする。
- 比率はタイトルなどを含む画像全体に適用する。グラフを縦につぶして合わせず、必要なら画像幅を広げる。
- タイトル・凡例・条件・軸名の実際の高さを計測し、折り返しても自然なグラフ領域を確保する。最小予約高76pxは横軸名を省略した場合も共通とする。
- プレビューの縮小倍率と出力用のサイズは分ける。画面に収めるための縮小を、保存画像のサイズ計算に使わない。
- 保存対象や比率を変えた場合は計測状態を更新し、前の画像の折り返し高さを引き継がない。

## 保存処理

- 保存対象の設定・データ・表示状態を同じ時点のスナップショットとして保持し、プレビューと実際のPNGへ同じ内容を渡す。
- ヘッダー・軸名の配置とサイズ計算、PNG生成、保存操作を共通化する。ページごとに同じ枠組みを複製しない。
- グラフ固有の計算や描画は利用側で扱い、共通の保存処理に持ち込まない。表や他の画像保存にも使う処理には、グラフ専用の配置を混ぜない。
- 複数グラフを上下に並べる場合は同じ幅を使い、入力順に配置する。既定のパネル間隔は12pxとする。各グラフの自然な高さを保ち、比率は画像全体へ一度だけ適用する。
- 共通のタイトル・凡例・条件は1回だけ表示し、各パネルには固有の情報を表示する。画像やスクリーンショットを引き伸ばして結合しない。

## 画像名

- 既定名は「対象・指標＋主要条件＋有効な表示設定＋縦横比＋`.png`」とし、人が内容を判断できる名前にする。設定ハッシュ、保存日時、乱数の識別子は付けない。
- 対象期間・集計対象・比較順序など、図を見分ける主要条件を先に置く。無効な設定、内部ID、画面の開閉状態、入力途中の未確定値は入れない。
- 計算結果の点配列や平均値など、結果データ自体は名前に入れない。ファイル名で計算結果の完全な同一性を保証しない。
- 禁止文字、予約名、Unicode、長さの処理は共通の命名処理で扱う。長い名前は主要条件を優先し、省略項目がある場合は末尾に `ほかN項目` と示す。Unicodeの文字を途中で壊さない。
- 比率なしは `_比率自動`、指定ありは `_比率16x9` などとし、同じ比率は既約比で統一する。比率を加えても名前全体の長さ上限を守る。
- 比率変更時には自動名も更新するが、ユーザーの手入力後は自動で上書きしない。名前と画像は同じスナップショットから作る。
- 保存先選択を使う場合は保存ボタンの操作直後に開始し、描画待機によってブラウザーの操作権限を失わないようにする。

## 変更時の確認

- プレビューに加えて、実際に生成したPNGを確認する。
- 長いタイトル・凡例・条件、多い系列、比率なしと横長の比率で、中央のタイトル、折り返し、ラベルの欠け、重なりを確認する。
- グラフ領域が縦につぶれず、軸名・目盛り・直接ラベルが見えることを確認する。
- 保存対象の切り替え、比率変更、手入力名の維持、日本語・禁止文字・長い名前を確認する。
- 共通処理の変更が、画面上のグラフ、計算結果、配色・線種、他の画像保存に影響していないことを確認する。
- 共通の配置やサイズ計算を変えた場合は、この仕様と必要な見本も合わせて更新する。見本が採用済みデザインの参考か、実装から生成した確認用出力かを区別する。
