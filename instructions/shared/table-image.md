# テーブル画像出力の仕様

このプロジェクトでテーブルの画像出力を作成・変更するときに適用する。グラフ画像の配置・サイズは [グラフ画像出力の仕様](chart-image.md) が扱い、表用の枠組みをグラフへ流用しない。実在する共通部品、見本、適用状況は利用側の仕様に記載する。

## 役割の分担

- 表の罫線・見出し・数値の表示は [テーブルの表示方針](table-ui.md)、比較の基準は [比較表の判定と共通化](comparison-table.md) と対象指標の定義に従う。この仕様では画像にする際の測定・配置・保存を扱う。
- 系列の色は利用側の共通配色定義を使い、表・凡例・プレビュー・PNGで同じ対応を保つ。画像保存のために別のパレットを作らない。
- 表全体の測定、文字サイズ、比率、寸法・画素数上限は、表画像用の共通部品・定義へ集約する。計算・集計・比較対象の選択は利用側が担当し、ページごとに保存処理を複製しない。
- 実在する部品・定義・見本への参照と使い方を利用側の仕様へ登録する。仕様を保存したことを、機能の実装・既存ページへの適用と扱わない。

## 固定仕様と変更できる入力

### 保存対象と比較基準

- 設定・対象データ・計算済みの値・表示する行列・並び順・比較基準・配色を、保存開始時点のスナップショットとして保持する。プレビューと実際のPNGには同じ内容を渡す。
- 表の転置や上下配置、複数画像への分割を行っても、元の値、分母、比較対象、比較基準を変えない。分割した範囲だけで集計し直したり、非表示の候補を比較対象へ追加したりしない。
- 数値に応じた濃淡を使う場合は、分割前の保存対象全体で色尺度を決めて保持する。各画像の最大値・最小値へ個別に合わせ直さない。系列色の意味と数値を表す濃淡を混同しない。
- 比較に使う値と表示用の丸め、欠損、同率、共通値の結合は、比較表の判定と対象指標の定義に従う。画像化や配置変更を理由に判定を変更しない。

### 配置と文字

- 保存対象の全文・全行・全列を保持する。画面のスクロール位置や表示領域だけを撮影して出力しない。明示的に選んだ行列を保存対象とする場合は、その対象条件を画像で確認できるようにする。
- タイトル・対象条件の帯は、折り返しを含む自然な高さを確保する。指定比率に合わせて文字やヘッダーを縦に引き伸ばさない。
- 比率指定によって縦方向の余白が生じた場合は、表のデータ行へ均等に配分する。見出しと数値の対応、行列の結合を維持する。
- 全対象数値セルの文字サイズを揃え、最も余裕のないセルに合わせる。最大値の対象名などを数値の代わりに表示する形式も、同じ役割の全セルでサイズを揃える。タイトル・見出しは別の役割として扱う。
- 文字サイズの初期値・選択肢は共通定義へ集約する。ページごとの固定値や、欠けを見逃すための個別縮小を追加しない。
- 比率指定がない場合は内容に必要なサイズを使う。指定比率でも全文・全行・全列を維持し、収まらない場合はエラーにする。文字・行・列を切り取った画像を保存しない。

### 描画倍率と上限

- PNGは出力用レイアウトの幅・高さをそれぞれ2倍にして描画する。プレビューの縮小倍率は出力用の寸法計算に使わない。
- 幅・高さ・総画素数の上限を共通定義で管理し、2倍描画後のPNG寸法と総画素数も検証する。未検証の上限を利用側に埋め込まない。
- 上限の値と判定処理は利用環境で確認し、定義元と検証方法を利用側の仕様へ登録する。
- 上限超過、描画の欠け、全文を保持できない状態では保存を止め、原因がわかるエラーを表示する。分割保存を用意する場合も、保存対象の抜け・重複を防ぎ、分割前の比較基準と色尺度を維持する。

利用ごとに変更できるのは、保存対象のデータ・行列・対象条件、タイトル、配置、対応する文字サイズと画像全体の比率などとする。共通の寸法・画素数上限や保存時の検証を、ページ側の設定で無効にしない。配置や文字サイズの選択肢は、対象の要件を確認して定める。

## 利用側が渡すものと保存の流れ

1. 計算済みの表、行列の見出し、対象条件、比較基準、配色を同じ時点で保持する。
2. タイトル・対象条件、保存対象の配置、文字サイズ、比率を共通の画像出力処理へ渡す。画像名と保存先選択は [グラフ画像出力の画像名・保存操作の方針](chart-image.md#画像名) に揃える。
3. 描画後に表全体と折り返した文字を測定し、欠け、寸法・画素数上限、全対象セルの文字サイズを検証する。
4. 同じスナップショットでプレビューとPNGを生成する。対象や配置・比率を変えた場合は計測状態を更新し、前の折り返し高さやセル幅を引き継がない。

上記は必要な入力と処理順であり、特定のAPIやコンポーネントの存在を示すものではない。

## 見本と適用状況の管理

- 利用側の仕様に保存機能・共通部品・見本の実装状況と適用済みページを記録する。仕様の追加だけを理由に既存テーブルの画面表示を変更しない。
- 実際の保存機能から見本PNGを作り、対象ページ、入力条件、配置・文字サイズ・比率、再生成手順を登録する。仮の画像を実装の確認用出力として扱わない。
- 見本の数値・対象名は入力例とし、将来の出力へ固定しない。仕様を変更した場合は実出力から見本も更新する。

## 変更時の確認

- 画面上の表、保存前プレビュー、実際のPNGで、値・対象条件・行列・並び順・比較結果・色が一致することを確認する。
- 長い対象名・見出し・同率名、多い行列、欠損値、共通値の結合を含め、全文・全行・全列、罫線、タイトル・対象条件に欠けや重なりがないことを確認する。
- 提供する通常・転置・上下・分割の各配置と、比率指定なし・横長・縦長を確認する。分割時は全対象を一度ずつ含み、比較基準・分母・色尺度が分割前と同じであることを確認する。
- 全対象数値セルの文字サイズ、ヘッダーの自然な高さ、データ行への余白配分、プレビューと出力寸法の分離を確認する。
- 寸法・画素数の上限付近と超過時、収まらない長い文字列で、欠けたPNGを保存せず適切にエラーになることを確認する。
- 共通処理の変更が既存の表表示・計算や他の画像出力へ影響していないことを確認する。実装変更では関連テストとビルドを行い、文書のみの変更では内容・参照先・適用範囲を確認する。
