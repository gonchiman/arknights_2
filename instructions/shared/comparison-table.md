# 比較表の判定と共通化

比較表で最大値・同率の強調、共通部分の結合、転置や分割を作成・変更するときに適用する。表の基本表示には [テーブルの表示方針](table-ui.md) を適用する。

- 比較対象、指標、単位、対象期間、基準値・分母を定め、比較対象外の条件は見出しとして残す。表示を切り替えても元の数値や比較条件を変更しない。指標固有の計算・集計・比較基準は利用側の定義に従う。
- 最大値や同率は選択された全候補の未丸め値から判定し、表示桁で丸めて最大候補を決めない。同率は浮動小数点の丸め誤差だけ許容し、同率の候補をすべて示す。非表示の比較元を自動的に候補へ追加しない。
- 比較候補に欠損・不正値があれば、その比較単位は比較不能とする。欠損候補だけを除外して最大を選ばない。
- 共通の行・列をまとめる場合は、他の比較条件を揃えたうえで、対象範囲の全セルの未丸め値が一致することを確認する。欠損や表示桁だけの一致では結合せず、共通化した条件を見出しへ明記する。
- 最大候補の名称をまとめる場合も、名称の一致だけでなく、比較した全候補の元の値が共通化する範囲で一致することを確認する。
- 転置・上下配置・条件別分割でも、各値の比較元と分母を維持する。比較値を濃淡で表す場合は、同じ指標・比較条件の表全体で色尺度を揃え、分割した各表で再計算しない。
- 系列の種類を区別する色と、数値を表す濃淡の意味を分け、利用側の共通配色定義を使う。画面・凡例・プレビュー・保存画像で同じ対応を保つ。
- 画面・コピー・計算詳細・保存画像へ、同じ設定・データ・表示状態を渡す。
