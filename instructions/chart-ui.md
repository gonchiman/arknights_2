# グラフの操作方針

このサイトの画面上のグラフについて、追加・修正の提案、設計、実装に適用する。

- グラフ本体は原則として閲覧専用にする。描画領域、軸の目盛り、評価帯、凡例に、クリックやホバーによる選択・強調・ツールチップ・詳細の切り替えを設けない。グラフ内のドラッグやズームも同様に扱う。
- 表示形式の切り替え、絞り込み、表示設定、画像保存などの操作はグラフの外に置く。画面幅が狭いときは、目盛りやラベルを読めるようにブラウザー標準の横スクロールを使ってよい。読み上げ用のラベルも利用できる。
- グラフ内の操作が要件に含まれる場合は、その用途に必要な操作に限って設ける。既存グラフの見直しは依頼された範囲で行う。

実装例は、DC3属性比較の [出現順位グラフ](../src/components/DamageCalculatorThreeAttributeRankChart.tsx) と [ゲーム内評価グラフ](../src/components/DamageCalculatorThreeAttributeRangeChart.tsx)。
