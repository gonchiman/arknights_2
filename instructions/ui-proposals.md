# UI案の画面見本

画面の見た目・情報配置・操作が変わる提案では、最初の回答に `visualize` で作った画面見本を表示する。直前まで画面について話していれば、「実装案を作る」「修正案」のような短い依頼にも適用する。利用者から形式の指定があれば、その指定を優先する。

- 配置を決める案では、実際の項目名と代表的なデータを入れ、画面を開いた直後に何が見えるかを示す。
- 切り替えや開閉が判断の対象なら、見本でもその操作を試せるようにする。複数案を比べるときは同じデータを使う。
- 回答を送る前に、見本が会話内で表示される形で含まれていることを確かめる。文章は選択理由や実装範囲など、見本だけでは伝わらない点に絞る。
