# UIの補足テキスト方針

このサイトの機能・UIについて、案を提示するとき、設計するとき、または実装するときに適用する。モックアップや比較案にも同じ方針を適用する。

- 補足テキストは原則として0にする。初期案から、説明文・ヒント・操作ガイド・注記などの補足を添えない。「丁寧に説明するため」「空白を埋めるため」といった理由で文章を追加しない。
- 補足テキストは、項目の意味や操作方法を説明する文章を指す。文字サイズの大小にかかわらず適用する。
- 見出し、入力ラベル、ボタン名、数値、単位、凡例、計算条件、現在の状態、入力エラーなど、識別や判断に必要な名称・値・状態を簡潔に示す表示は補足テキストと区別する。ただし、これらに追加の解説文を添えない。
- 説明を添えないと伝わらない場合は、先に名称、項目のまとめ方、配置、操作の流れを見直す。短いラベルと画面構造で意味が伝わる形を優先する。
- 既存のUIや共通部品を再利用するときも、既存の補足テキストの量をそのまま引き継がない。この方針を満たすために必要な範囲で調整する。
- 補足テキストを減らす代わりに、ツールチップ、ヘルプ、折りたたみの説明などを自動で追加しない。ユーザーが説明の表示を求めた場合は、その指定された範囲で追加する。
- 既存画面の見直しは、依頼された作業範囲に適用する。この方針の追加だけを理由に、無関係な画面の文章を一括削除しない。
