# ローカル開発サーバーの起動場所

開発サーバーを起動・再起動するとき、配信元を確認するとき、または `main` の作業フォルダを切り替えるときに適用する。

- `main` は利用者が普段使うクローン先で開き、そのフォルダから `localhost:5173` を起動する。Windows での配置例は `%USERPROFILE%\Documents\arknights_2`。端末ごとに利用者が指定したクローン先を使う。
- 起動前に `git worktree list` と起動元での `git branch --show-current` で、クローン先が `main` になっていることを確認する。`main` が別の作業フォルダで開かれている場合は、未コミットの変更を確認し、利用者が指定したクローン先で `main` を開けるようにする。
- `main` 用のサーバーはクローン先で `npm run dev -- --host localhost --port 5173 --strictPort` を実行する。5173番が使用中の場合は、動作中のサーバーの配信元を確認する。
- 機能開発は別の作業フォルダで行い、確認用のサーバーは別のポートで起動する。
