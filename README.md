# Arknights Skill Analyzer

アークナイツのゲームデータからスキル効果タイプを自動分類し、判定根拠・信頼度・例外を確認するための分析ツールです。

## 技術構成

- Vite
- React
- TypeScript
- ArknightsAssets/ArknightsGamedata の JP データ
- GitHub Pages

## 開発

```bash
npm install
npm run dev
```

ビルド確認:

```bash
npm run build
```

敵の登場ステージ数データを更新:

```bash
npm run generate:enemy-stages
```

`stage_table.json` の戦闘ステージを `levelId` 単位で重複除去し、各Level JSONから `public/data/enemy-stage-appearances.json` を生成します。取得できなかったLevelと未対応の敵IDは生成物の診断欄に残ります。

## ディレクトリ

```text
src/
├─ components/    # UIコンポーネント
├─ lib/           # 分類・データ取得・CSV・保存などのロジック
├─ types/         # 型定義
├─ App.tsx
├─ main.tsx
└─ index.css
```

分類ロジックは `src/lib/classifier.ts` に集約しているため、UIを触らずにルールを追加・修正できます。

## 現在の機能

- オペレーターデータベース
  - 頭文字・職業・レアリティ・文字列による絞り込み
  - 最終昇進・最大レベル・信頼度100時点の基本ステータス一覧
  - 潜在能力・特性・素質・全スキル・標準モジュールの詳細表示
- 全スキルのテーブル一覧・検索・絞り込み・列ごとの並び替え・効果詳細モーダル
- Skill Effects（`#/skill-effects`）で、スキル説明文から効果とその内容を一覧化
  - 専用ページでオペレーターを検索し、スキル・レベルを選択して解析結果を表示
  - 選択内容をURLに保持し、再読み込み・戻る／進むでも同じ対象を表示
  - 「効果」列には、説明文の変数が参照する元データのキーを表示
  - 説明文の根拠・文脈の確認、解析結果と選択レベルの元データをJSON詳細モーダルで表示・コピー
  - 説明文の変数を展開してルールに合う効果を読み取り、解析できなかった記述・値を取得できない変数を表示
  - 浮遊ユニット・ブロック・治療対象・チャージ・弾薬の数、能力値、回復・バリア、ダメージ、状態異常の時間など、明記された表現に対応
  - 加算量・変更後の値・倍率・上限・毎回の量と発生間隔を区別。条件・対象は根拠の文章と文脈に保持し、効果を無条件に自身へ適用しない
  - 数値が不明な強弱表現、解決できない変数、意味を確定できない独自効果は推測しない。固定の数字からblackboardのキーを逆引きしない
- オペレーターデータベースのスキル名から分類詳細をポップオーバー表示
- `duration` / `durationType` / 説明文による自動分類
- 判定根拠と信頼度の表示
- 手動分類の上書きと LocalStorage 保存
- Raw JSON 表示
- ダメージ計算機（初期版）
  - オペレーターの昇進段階・レベル・信頼度、スキルレベルを反映
  - モジュールとLvを選択し、能力値補正と登録済みの特性・素質変更を反映
  - 通常攻撃と単純な攻撃系スキルの1ヒット・DPS・総ダメージ
  - 敵の防御力・術耐性と、敵ステータス別の比較表
  - ゲームデータから推定した倍率・ヒット数・攻撃間隔の手動調整
- オペレーター比較
  - 終了条件・職業・レアリティ・名前などによるスキル絞り込み
  - 終了条件に応じたダメージ・DPS・スキル総ダメージの切り替え
  - 防御力と術耐性を組み合わせた最大10個の敵条件で横断比較
  - 最大スキルレベルの効果・発動情報を詳細モーダルで表示
  - 表示中の比較結果をUTF-8 CSVで出力
- 敵分析
  - 敵図鑑と敵戦闘データを敵IDで結合
  - 敵ごとの登場ステージ数を一覧・詳細・統計グラフ・度数分布表へ表示
  - 敵名・図鑑番号・能力・区分・攻撃種別による検索と絞り込み
  - HP・攻撃力・防御力・術耐性・移動速度・攻撃間隔・重量・状態異常耐性を一覧表示
- 参照元
  - 外部データのファイル単位の用途と取得方法を一覧表示
  - 表示時に直接取得するデータと事前集計スナップショットを区別
  - サイト内で加工・算出する分類、ダメージ、統計、敵ランクの由来を明示
  - 敵の登場ステージ数スナップショットの生成日時・処理状況を表示

ダメージ計算機の初期版は、確認済みの特性・素質と選択したモジュールを反映します。潜在・味方バフ・対象数・攻撃モーションはまだ扱いません。条件付きのモジュール効果、召喚物、設置物、周期ダメージ、段階・モードを持つスキルは、誤った数値を出さず未対応として表示します。

## 分類について

現在の分類器はヒューリスティックです。`durationType = AMMO` などの構造化データによる高信頼ルールと、説明文による中・低信頼ルールを分けています。今後は既存の手動分類データを正解データとして照合し、ルールを改善する想定です。
